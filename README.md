# Satzklar

Satzklar rechnet aus, was deine Stunde bringen muss, und macht daraus Angebot und Rechnung. Offene und überfällige Beträge stehen in der Übersicht. Die Daten bleiben im Browser.

## Start

```bash
npm install
npm test
npm run dev
```

Der Rechner liegt auf der Startseite. „Rechnung mit diesem Satz“ öffnet einen Entwurf mit dem aufgerundeten Stundensatz. Drucken speichert über den Browser ein PDF.

Beim ersten Öffnen liegen Beispieldaten im Studio. Sie sind als Beispiel markiert. „Beispieldaten entfernen“ löscht sie.

Der geplante Pro-Preis ist nicht buchbar. Es ist kein Zahlungsweg angeschlossen.

## Gestaltung

Die Oberfläche folgt `DESIGN.md`, dem UI/UX-Pro-Max-System unter `design-system/satzklar/` und den Open-Design-Skills in `.agents/skills/`.
